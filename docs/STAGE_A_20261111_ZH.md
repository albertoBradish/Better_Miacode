# 阶段 A 编辑安全与预览设置

本轮基于 2026-11-11 开发目标推进阶段 A；本文件描述候选行为，验证结果另见工作区 exports/stage_a_20261111。

- CLI 图形后端与导出后端保持一致，修复强制 OpenGL 时仍初始化 D3D11 所致的崩溃；OpenGL 导出会话拒绝不匹配的进程图形 API。
- 片头样式复制不再携带其他谱面已解析的 demo/drop 起止时间；手动区间仍保留。导出快照按当前文档重新解析自动区间，避免沿用旧位置。
- 批量调整仍只作用于当前选区。修改跨越编辑区可见范围、折叠行或横向不可见内容时，先显示影响行范围与前后摘录，默认取消。确认时核对文档、难度、作用域、revision 和原文，失效则拒绝应用。应用沿用原生一次撤销事务。
- 暂停时显示 PV/背景与显示判定区分别配置。新配置默认均显示；旧版明确设置按旧效果迁移，随后可独立选择。导出不使用交互暂停状态。
- 移除暂停显示的 Alt 按住反转及快捷键注册。首选项增加禁用单按 Alt 激活应用菜单，默认开启；不改操作系统任务栏，不拦截其他键的 Alt 组合。
- PV 帧率页说明刷新限制、显示器刷新率与源视频帧率的区别。没有新增“跟随源 PV”模式。
- 失分计算保留官方 EX 判定规则；Mine 等扩展谱面仍明确拒绝完整官方失分计算。默认不显示零数量 Mine 项，不新增未经定义的扩展计分算法。
- 手序分支开启自动补全时切换为 INS 并持久化；加载已有配置不强制改写用户模式。此处指编辑器补全，不是自动手序求解。

PV 位置与 4K 问题按样例排查；未复现的场景不得标记修复。竖屏导出当前被接口明确拒绝，不在本轮擅自扩大导出格式支持。后续正式发行、公开私有仓库边界和固定测试安装沿用工作区约定。
