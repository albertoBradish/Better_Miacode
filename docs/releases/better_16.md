# Better Miacode 2.1.0-better.16

## 谱库

- 谱库新增 MiaCode 2.1.0 的难度筛选。可以同时勾选多个难度，列表会显示至少包含其中一个难度的曲目。难度筛选可以和搜索、曲包及分类一起使用，清除筛选即可恢复全部难度。
- 从筛选结果打开曲目时，编辑器会选中匹配的难度。现有 `.miabundle` 谱库、多曲目标签和批量操作均可继续使用。

## 工作区与编辑

- 修复预览左置。经典、编辑、预览三个工作区都会按所选方向排列编辑器和主预览。
- 「谱面整理」支持自定义快捷键。绑定单键后，在谱面正文中按下该键即可整理当前谱面。其他普通按键继续用于输入，空格仍遵循防误触设置。

## 文案修正

- 中英文使用说明和命令行帮助写明高级功能位于「首选项 → 高级」。使用说明也写明自动整理谱面默认关闭，空格防误触和空难度提醒默认开启。
- 批量导出找不到音轨时，会提示检查 `track.mp3`、`track.wav`、`track.flac` 或 `track.ogg`。
- 移出谱库、删除曲包和删除谱库失败时，提示会写明对应操作。删除谱库遇到原文编辑时，会区分仍打开的编辑页和等待恢复的编辑内容。
- 批量整理谱面和整理元数据分别显示各自的 100 份上限和进度提示。以上界面提示已同步至中文、英文和日文。
