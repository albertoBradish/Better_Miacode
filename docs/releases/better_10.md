# Better Miacode 2.0.1-better.10

本版基于官方 `release/2.0.1` 的 `8a0b44f8e0944c97a35c0978e0ffcb842c55ed0b`，包含该基线的关键修复，并保留 Better Miacode 的独立配置与既有增强功能。

## 功能

1. 视频模板：保存、选择、重命名、删除、导入和导出。保存导出设置，保留本次任务的谱面、目标路径及区间。
2. 多封面：单曲和批量均可复选模板；冻结画面后导出，按模板生成独立文件名，已有封面不覆盖。修复关闭选项的翻译键名。
3. CPS：同一时刻的一组 Touch 计一次，物件数量与 DX 分母保持原统计口径。
4. 失分：隐藏零失分与不可发生的判定行，增加 SSS／SSS+ 的 Tap Great 等价预算，精简说明。
5. BPM 导入：识别音频时间格式和空 maidata，保留音符的绝对音频时刻与持续时长；严格语法和重新解析校验通过后，以一次事务应用到当前难度，支持撤销、重做，拒绝过期预览。
6. 体积预算：30／100／200 MB，计入完整渲染时长及音频、封装余量，成片按实际字节检查，必要时修正码率重编码。30 MB 为 480p、无视频 PV；原有档位显示当前码率参数。
7. 分辨率：360p、480p、540p、2160p，覆盖 1:1、4:3、16:9。

默认界面字体继续使用已整合的阿里巴巴普惠体。七项功能的实际图片和动图均位于 [README](../../README.md#本次更新与演示)。

## BPM 与编码边界

- 仅替换当前难度，不改共享偏移或其他难度。时间保持误差验证上限为 1 微秒；无法安全表示时拒绝修改。
- 保留音频时刻可能需要非 384 分音。预览明确提示相应分音，继续转谱前需核对目标工具的支持情况。
- 导入窗口中的预览可先检查；源正文、难度或 revision 改变后不能应用旧结果。
- MB 是十进制，目标约束 MP4，不约束另存的无损 WAV。目标档使用按码率的软件编码，实际大小低于上限时不填充文件。
- 同步封面失败会报告，并保留已成功的视频。取消和失效任务丢弃待写封面。

## 本轮验证

Windows x64，Release，构建并发不超过 4；全部使用合成谱面和独立 runtime。

- 13 项聚焦检查通过：chart_tools、video_export_runtime_policy、cover_layout_model、qml_export_video_page、export_file_picker、chart_workspace_file_service、document_model_save、runtime_isolation、muri、cover_export_session、video_export_visual_aids、video_export_intro_mode、video_export_audio_render_plan。
- BPM 覆盖负偏移、精确 BPM、拍号、Hold／TouchHold、分支 Slide、HS、注释、空谱与非法输入。原生窗口验证一次撤销还原原文、重做还原应用结果，保存后正文逐字一致。
- 360p、480p、540p、3840×2160 均已实际导出并完整解码。
- 30／100／200 MB 短片均低于目标字节数。30 MB 请求 1920×1080 时实际输出 854×480，禁用 PV；100／200 MB 保留 PV。
- 单曲与批量分别实际生成 1 个视频及 2 张模板封面，批量汇总显示封面成功 2 项、失败 0 项；完整 30 MB 档视频约 15.2 MB。
- README 使用实际窗口截图、实际渲染帧及由这些素材编码的动图，无真实谱面或正式版用户数据。

Windows ARM64、macOS 未做本轮原生构建或人工验收。本说明不表示已经发布多平台 Release；发行附件与归档哈希以最终交付记录为准。
