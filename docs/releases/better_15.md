# Better Miacode 2.0.1-better.15

## 谱库

- 「导入乐曲」支持单曲和批量导入。导入时会检查谱面格式，跳过歌词、说明等普通文本。将新谱面保存到已打开的谱库后，列表会自动刷新。
- 分类筛选新增「无分类」。曲目可按曲名、曲师、谱师、BPM、版本、流派或谱面定数升序、降序排列。曲名按数字自然排序，官方版本按发行顺序排列，自定义版本排在其后。缺少精确定数时按等级换算，例如 14+ 按 14.6、13？按 13.0 排序。
- 进入「批量操作」后可点击整行勾选，按住 Shift 连选一段曲目。选中后可在顶部整理谱面、导出、移出谱库、添加到渲染任务或整理元数据。面板较窄时从顶部菜单选择操作。
- 元数据编辑提供官方版本、流派和版本分类候选。批量整理元数据可补全 BPM 和版本，并将写在等级栏的小数定数移入定数栏。删除谱库或曲包时须输入对应名称。

## 预览与工作区

- 主预览和各个子预览分别根据自己的谱面选择判定线。延迟校准沿用原生判定线。同步播放相同背景时共用媒体源，每个子预览可在窗口内关闭。
- 播放音频跟随取得焦点的预览，鼠标经过时继续播放当前声源。切换时会预缓冲音频并渐变音量。主预览下方的音符统计可在预览设置或画布齿轮菜单中开关。双列统计中的 Rate 与第二列对齐。
- Ⅰ、Ⅱ、Ⅲ 默认打开「经典」「编辑」「预览」工作区。时间轴可在当前位置切换「横向」「下落」「上落」。热力图移至预览设置，小节线和启动拍选项可从画布菜单调整。

## 导出与手序

- 打包 ZIP 时可同时生成无 PV 副本、仅导出基础元数据，或自动整理导出的谱面。
- 「谱面预览」片头的判定圈内跟随画面设置中的「亮度（内侧）」，圈外使用片头的「背景/PV 亮度」。实时预览与导出视频采用同一设置。
- 手序拆解结果显示位置、状态和用手建议。打开视频导出页时会收起「配置候选」等编辑控件，返回编辑页后恢复。
