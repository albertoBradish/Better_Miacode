# Better Miacode 2.0.1-better.14

- 工作区工具栏新增 Ⅰ、Ⅱ、Ⅲ 三个槽位。保存自定义布局时可绑定槽位。管理工作区支持排序，选中布局后可与当前布局对照，再决定是否应用。
- 谱库支持 Ctrl + 鼠标左键单击，在额外标签页打开谱面。
- HUD 默认使用阿里巴巴普惠体，原字体仍可选。右上角的 BPM、CPS、MOD 和拍号等信息可独立设置字体。调试渲染新增高级信息总开关，默认关闭。
- 判定线和完成度显示默认自动检测。优先使用谱面 metadata 声明的版本，否则按当前难度使用的最新元素判断。完成度也可选「标准」「现代」或「默认」，分别显示 FiNALE Rate、DELUXE Rate 或两项。
- 启动拍击打时轨迹已经全亮或恰好全亮的 Slide 使用原版淡入时机。游戏设置可调节星星淡入时间，范围为 −1 至 1，步长为 0.1。
- 修复「谱面预览」片头的曲绘和 PV 只覆盖右侧的问题。难度卡阴影默认开启，片头背景和 PV 的默认亮度为 80%。
- 手序拆解保留自动手序。旧配置首次启用、以及每次关闭后重新开启，都需要输入离线密码。

[本版完整对应源码与构建脚本](https://github.com/albertoBradish/Better_Miacode/tree/v2.0.1-better.14)
