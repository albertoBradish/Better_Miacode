# 工作流更新开发候选

基于固定的上游 dev `be494a567869b407fd17acad33482af6ad1c664d`，保留此前 Better 的编辑、选择、BPM/HUD、预览辅助、模板与多封面能力。此分支供本地验收，正式线上 Release 尚待用户手动确认。

## 本轮变化

- 时间轴支持 Alt＋滚轮连续缩放，隐藏原百分比控件；提供四种键位排列、两种纵向位置及上落/下落方向，并配布局示意图。
- 高级元数据表单默认关闭，在首选项“关于”开启；歌曲、分类/版本、试听、作者备注和分难度资料分别编辑。
- 本地音频结构与谱面压力分析提供 drop 候选；结果可人工调整并保存在 maidata，试听窗口独立保存。压力为估计，不是官方定数。
- 压力以预览底部灰白半透明曲线显示，drop 以播放进度条小标记显示；原始压力数据不因视觉平滑改变。
- 新增黑底调试渲染，保留谱面并跳过背景媒体；底层透明 alpha 合成已提供基础接口，本轮不新增透明视频或帧导出入口。
- 低性能模式默认关闭，优先 60 Hz 基础预览并冻结播放中的自动时间轴更新；暂停、停止和结束时同步，原帧率偏好保留。
- 防空格误触默认开启：单按播放/暂停，600 ms 内三连按解锁文本空格，失焦重锁。
- 自动整理默认开启：首次打开 maidata、ZIP 和渲染任务采用当前整理设置；先保留原字节备份，不暗中保存其他未保存难度。普通播放不整理，其他文本格式首开不自动改写。
- ZIP 的空难度警告默认开启、默认取消；取消或失败保留已有目标文件。
- Slide 头星和轨迹可独立选择和编辑；无法保留未选组件语义的操作明确拒绝。
- Slide 判定时值子选项迁入首选项；更多显示展开后改为“收起更多”。
- 视频区间可采用 drop；新增“谱面预览”片头，左侧信息卡、右侧谱面，保留允许的 PV/BG。
- 体积预设为标准、30/100/200 MB 和自定义目标码率；PV 开关独立。旧设置、模板及工作进程参数保持兼容。
- 同步封面保留多选但简化提示；批量输出默认当前谱面目录；新模板后缀为 `.miatemplate`，仍可导入旧 JSON。
- 狐狸仅在 drop 跳跃，其余播放区间按 BPM 摇头，过渡保持连续。

公开 HandOrder 下放时保留人工标注与分色，并可用已有左右手标注增强压力估计；公开实现不包含自动手序推断。

## 文件与兼容性

原始备份位于谱面目录 `.autosave/*.bak`。自动操作先验证原始字节与保存点；冲突、备份失败或外部修改时停止。逻辑 LF/CRLF 统一，但备份和哈希仍针对原始字节。

自动 drop、用户试听窗口与导出区间具有独立来源；人工选择优先。密集分析数据存于产品独立缓存，不把整条热图塞入 maidata。
