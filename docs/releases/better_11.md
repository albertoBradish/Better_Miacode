# Better Miacode 2.0.1-better.11

基于 MiaCode dev 固定基线 `be494a567869b407fd17acad33482af6ad1c664d`。

以下列出 Better Miacode 相对原版的新增与增强功能，包含此前版本保留的能力。

## 对象选择与编辑

1. **行号定位与选区试听**：行号定位并暂停；选区试听保留进场及长音尾部。

2. **三处联动选择**：源码、时间轴、预览同步；Shift 框选，头星与轨迹独立选中。

3. **非连续对象编辑**：复制、剪切、删除及已有变换命令作用于对象集合，可撤销、重做。

4. **保留上下文的剪贴板**：携带 BPM、分音、HS、拍号与空拍，粘贴后恢复目标时序。

## 时间轴增强

5. **连续缩放**：Alt＋滚轮无级缩放，保留原有自定义快捷键。

6. **独立音符大小**：音符可放大至 300%，与时间轴时间缩放分别调整。

7. **纵向时间轴**：置于编辑区左侧或右侧；可选上落、下落，播放线靠边。

8. **四种键位排列**：12345678／56781234／87654321／43218765。

## 自由工作区

9. **拖动停靠与标签组合**：面板可自由重排和组合，单面板不增加重复标题。

10. **扩展面板浮动与显隐**：编辑器、大纲、时间轴、语法、无理均可独立管理。

11. **命名布局**：保存、切换和重置工作区，布局预设集中到同一菜单。

12. **工作区快捷操作**：Alt＋W 打开菜单；反引号最大化、还原当前模块。

## 判定辅助与渲染

13. **小节对齐参考线**：支持默认检测、自定义拍数和源码行首三种模式。

14. **Slide 判定骨骼**：显示实际判定区，覆盖链式 Slide 与 WiFi 分路。

15. **Slide 判定时值**：最早 Perfect 时全亮；支持启动拍规则，保留正常轨迹消退。

16. **黑底调试与图层控制**：新增黑底调试与无判定线选项，调试设置与常规模式隔离。

## 预览信息与谱面资料

17. **信息 HUD 扩展**：BPM、CPS、Meter、Mods 分别开关，预览适配自由比例。

18. **CPS 与显示精简**：同拍 Touch 按组计数；编辑画布移除重复物量统计。

19. **高级信息表单**：填写各类 ID、版本、定数、试听区间、日期和作者备注。

20. **DX 失分与容错**：计算 SSS／SSS+ 预算和 Tap Great 容许数，含 Break／EX 约束。

## Drop 与压力分析

21. **自动推荐 Drop**：结合音频与谱面分析提供适合预览的候选区间。

22. **手动设定与取消**：支持拖动调整、源码选区右键设置，以及撤销和重做。

23. **保存并联动导出**：写入 maidata，人工选择优先；进度标记、片头与导出区间共用。

24. **可定位的压力热图**：综合位移、上下文和耐力；留白归零，可点击或拖动定位。

## 视频导出增强

25. **视频模板**：保存、应用、重命名与导入导出；使用 .miatemplate，兼容旧 JSON。

26. **体积与码率控制**：新增 30／100／200 MB 预设、自定义 Mbps；PV 可独立开关。

27. **新增分辨率**：加入 360p、480p、540p 和 4K，覆盖现有三种导出画幅。

28. **谱面预览片头**：左信息卡、右谱面；继承预览背景设置，隐藏编辑辅助。

## 封面与 BPM 工具

29. **一次同步多张封面**：内置、用户及布局模板可组合；批量输出默认当前谱面目录。

30. **封面文字效果**：新增描边与阴影，可调颜色、宽度、透明度、模糊及偏移。

31. **BPM 导入与应用**：导入音频时间或空 maidata，预览后应用；保留音符时间，可撤销。

32. **三种 BPM 导出**：顺序、音频时间、空 maidata；可预览、复制和保存。

## 编辑流程保护

33. **自动整理与原文备份**：首次打开 maidata、ZIP 和渲染前整理，备份至 .autosave。

34. **空难度导出提醒**：ZIP 打包发现空难度时提示，默认取消，可在首选项关闭。

35. **空格防误触**：单按播放／暂停，短时三连解锁文本空格，失焦后重锁。

36. **低性能模式**：优先 60 Hz 基础预览，减少界面特效及播放中的时间轴刷新。

## 使用与可靠性

37. **Better 命令行**：统计、视频、封面、BPM 任务；支持 JSON 请求与进度输出。

38. **独立运行数据**：配置、缓存、会话与日志独立保存，不迁移原版或手序版数据。

39. **狐狸律动升级**：非 Drop 自然眨眼、随拍摇头；Drop 闭眼跳跃并平滑过渡。

40. **导出与保存修正**：修复尾帧丢失和 CRLF 保存误判；失败或取消保留已有输出。


## 安装与版本范围

- 本次准备 Windows x64 Release 包；其他平台未在本次本机验证。
- 完整解压后从根目录 `MiaCode.exe` 启动，更新时保留本产品独立的 `runtime/`。
- 谱库管理仅进入下一版规划，本版不包含谱库扫描或迁移。
