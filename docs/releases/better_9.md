# Better Miacode 2.0.0-better.9

本次更新修复预览框选后无法继续使用编辑快捷键的问题，增加时间轴框选，并整理视频导出的显示选项。以下为相较于 better.8 的变化。

## 框选和编辑

- 预览与时间轴音符区域统一使用 Shift + 左键单击或拖框。命中的完整音符会切换选中状态：未选的加入，已选的移除；空框保留原有选择。Ctrl/Command 不再承担对象点选或加选。
- 新增时间轴拖框和框选轮廓。标题条继续定位，普通拖动继续平移；Esc、丢失鼠标捕获、谱面或坐标变化会取消未完成框选。
- 框选结束后焦点交回源码编辑器，复制、剪切、删除及镜像、旋转等编辑快捷键可直接处理该对象集合。非连续对象不会修改中间未选的音符，一次操作可一次撤销。

## 视频导出

BPM、CPS、Meter、Mods、小节线、判定骨骼及 Slide 判定/启动拍显示选项默认收起在“更多显示”。展开或折叠仅改变界面，不改变已保存的开关值或导出快照；Slide 启动拍子选项保留原有父项依赖。

## 下载与验证

发布目标为 Windows x64、Windows ARM64 与 Apple 芯片 macOS（13+）。各平台附件提供 7z、SHA-256 和自动验证报告；发布流程要求三平台来自同一发布提交并通过归档、CLI、合成视频及封面检查。

本轮 Windows x64 的对象选择、实际窗口拖框、选择反选、复制/删除和导出显示折叠聚焦检查已通过。测试只使用合成谱面和独立 runtime；Windows ARM64/macOS 未进行人工 GUI 验收，各平台自动验证范围见附件。macOS 沿用现有签名流程，未声称完成 Apple notarization。

Windows 完整解压后从根目录 `MiaCode.exe` 启动；macOS 打开 `MiaCode.app`。配置继续与原版和手序版隔离，不迁移偏好、最近文件或恢复内容。本版本不包含手序推断算法。
