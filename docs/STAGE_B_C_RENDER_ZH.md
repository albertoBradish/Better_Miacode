# 预览显示与时间轴改进

热力图提供关闭、经典独立条、画面叠加三种选择，入口位于预览渲染模式菜单。两种显示调用同一个 ChartStructureModel 的 pressure curve 和 heatmapSpans 缓存，不重新分析谱面。独立条位于预览画面与播放进度条之间，使用彩色柱形和当前播放位置线；画面叠加保留半透明单色曲线。关闭时不占独立条空间。样式保存至独立产品偏好的 ui.pressure_heatmap_style，旧配置保持画面叠加。

经典色条的配色参考本仓库 897813b9 的 PreviewPane.qml；当前叠加曲线参考 f3e09c2d。此实现恢复彩色条的阅读方式，并新增独立条布局，不声称像素精确回滚到尚未确认的测试版本。

时间轴缩放范围为 25–1200%，预设增加 400、600、800、1200%。连续 Alt 滚轮沿用原有鼠标时间锚点、横纵投影和命中几何；时间轴设置中提供 100% 恢复按钮。音符大小缩放仍独立保持原范围，放大时间轴不放大音符字形。对应交互 spec 增加横向、上落、下落的 600/1200% 锚点和有限几何检查。

调试渲染增加精简和详细诊断图层预设。精简保留判定区域与时间戳，详细另启用 BPM、CPS、判定点和触碰轨迹；仍可逐项调整。预设通过现有共享渲染设置写入并被视频快照取用，不依赖实时性能计数器。普通/无理/调试仍使用各自既有配置档案，TRG 未定义且不声明兼容。

公开手序版另在同一渲染菜单提供人工手序叠加开关，复用 showHandOrderAnnotations。它与普通、无理、调试渲染正交，不更改谱面、不触发自动推断。导出沿用现有默认跟随预览的手序选项，可在导出页明确覆盖。

本说明描述候选实现；构建和自动测试由主线统一执行，视觉与交互由用户本地验收。
