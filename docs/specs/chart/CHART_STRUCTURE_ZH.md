# 谱面压力与 Drop 区间

预览底部以灰白半透明面积曲线叠加当前难度的谱面压力，进度条上的淡黄色小刻度标出 Drop 起止。热图全宽对应媒体时长，点击或拖动可定位播放。播放中拖动会暂停预览，松开后从定位处继续。导出与片头试听期间隐藏热图。

悬停可查看判定 TPS、同时触击、位移、节奏、长按、滑轨、操作重叠和持续负荷。压力使用键位与触屏几何、相邻触击的实际秒差、重复和折返、长按与滑轨的共同占用估算。连续高负荷累积疲劳，留白使其恢复。曲线是 0–100 的估算，分析只保留按时间聚合的分量，不生成手序标注。

结构分析在后台读取本地音频，用短时能量、正向频谱变化、低高频带和重复段描述音乐结构。自动候选的置信度由音乐变化决定，当前难度的谱面压力参与候选排序。缺少可用音频时仍计算谱面压力。静音、过短音频和无明显结构变化的曲目可能没有有效 Drop。候选可以在区间编辑器中选用，应用后成为手动区间。

## 时间与保存

Drop 使用与预览播放位置一致的媒体秒数。原始谱面时间加 `first` 后用于采样压力。显示、导出和狐狸动画消费同一个已解析区间。

每个难度的选区写入 `maidata` 的以下字段，`N` 为难度编号。

```text
&miacode_drop_start_N=12.5
&miacode_drop_end_N=20.5
&miacode_drop_source_N=auto|manual
&miacode_drop_version_N=2
&miacode_drop_fingerprint_N=...
```

自动指纹含算法版本、音频内容 SHA-256、难度正文和影响解析时间的参数。输入变化后，旧自动结果在当前会话失效。手动区间可输入秒数或拖端点，同一会话支持撤销和重做。音频替换会提示复核，越界手动区间暂停供播放与导出使用。保存前备份原始文件，仅保存元数据区。只读、外部修改或其他保存失败时，选区保留在当前会话。

`demo_seek` 和 `demo_len` 仍是全曲试听窗口。缺少试听窗口时，可从 Drop 初始化一次，并用 `miacode_demo_source=auto` 标记。片头先采用本次显式区间，自动模式随后采用有效的手动试听窗口，再取有效 Drop，最后使用默认起点。跟随 Drop 模式跳过试听窗口。试听段按片头时长和媒体尾部裁剪。

Better Miacode 在独立运行目录的 `cache/chart-structure` 缓存音频特征和难度压力。正在播放时暂停后台分析，低性能模式延长空闲等待。狐狸按预览的四分音符节拍摇头，尾巴跟随，进出有效 Drop 时与原跳跃动作平滑过渡。
