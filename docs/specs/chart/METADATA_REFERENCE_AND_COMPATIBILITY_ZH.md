# 高级字段参考与兼容约定

高级信息表单复用 `AdvancedMetadata` 字段注册表，提供用途、单位、示例和参考值。建议值不等于目标平台的完整枚举；`cabinet`、`genre`、`version`、`regulation_N` 仍允许其他文本。编号保留前导零，定数与显示等级分开。非法日期、URL、数值、拍号与嵌套字段赋值在写入前拒绝，并在对应输入附近显示错误。

## 现有字段归属

| 字段 | 范围与语义 | 编辑入口与保存约定 |
| --- | --- | --- |
| `wholebpm` | 全局正数 BPM，供参考与预备拍使用 | 高级信息；不改写谱面中的变速 |
| `whole_time_signature` | 全局初始拍号，正整数分子/分母 | 高级信息；沿用时间元数据解析器校验 |
| `clock_count` | 非负整数预备拍数，0 关闭 | 高级信息；清空时文档恢复既有默认值 4 |
| `demo_seek`、`demo_len` | 全局试听起点及长度，媒体秒 | 高级信息；显式编辑会标记来源为人工 |
| `seek`、`wait` | 旧格式时间字段，媒体秒 | 保留兼容输入，不擅自替换 `first`；目标工具支持情况单独核对 |
| `desid_N`、`level_constant_N`、`regulation_N` | 难度槽位 1–7 的谱师编号、定数和规则标签 | 高级信息；不存在的难度不会因这些字段自动生成谱面 |
| `miacode_drop_start_N`、`miacode_drop_end_N` | 当前难度重点区间起止，媒体秒 | 预览区间编辑器维护；高级信息中只读查看 |
| `miacode_drop_source_N` | `manual`、`auto` 或 `disabled` | 专用编辑器维护，保留人工禁用意图 |
| `miacode_drop_version_N`、`miacode_drop_fingerprint_N` | 自动结果算法版本与输入指纹 | 专用分析流程维护，不允许高级表单制造有效性凭据 |
| `miacode_demo_source` | 试听区间归属，`manual` 或 `auto` | 专用流程维护；高级信息只读 |
| `miacode_bookmarks` | 编辑器书签序列化数据 | 原生书签工具维护；高级信息只读 |
| 其他未知字段 | 外部工具或后续版本的扩展 | 不因高级表单开关、参考选项或注册表更新而删除 |

## 不做无依据的字段迁移

目前没有经验证的通用字段与难度级 drop、算法指纹、书签语义完全等价，因此继续使用已有命名空间。试听区间与重点区间相互独立，禁止把 `miacode_drop_start_5` 直接改写为 `demo_seek`。本轮没有声明某个外部播放器、投稿站或格式一定接受这些扩展，也没有自动过滤未知字段。

已有键按不区分大小写的方式读取；高级表单修改其拥有的字段时使用注册表中的规范小写键。修改前仍执行现有冲突检查和原文件备份，整份文档继续由 `ChartWorkspace` 管理。只读的派生字段不能通过高级表单 setter 绕过专用编辑器写入。未知字段的值遵循既有文档读写规则保留，不承诺重排后字节级格式完全一致。

## 失分方案输入

失分工具新增判定数量输入、当前规则与计分基数、汇总失分和达成率。未输入对象按最高判定计算；不同判定行不能重复消费同一可用音符。非 EX、可降级 EX 长按尾部和全体 Miss 的库存逐级约束，因此单行不超限仍可能因组合重复使用而拒绝结果。输入无效、谱面为空或存在不支持的计分扩展时不展示有效达成率。谱面或难度版本变化会重置输入；SSS 独立容错参考可单独展开。

验证入口：`chart_tools_spec` 覆盖混合判定库存、全 Miss、负数、空谱及扩展对象拒绝，以及字段拍号、预备拍、开放参考值与未知字段往返；完整界面由用户本地验收。
