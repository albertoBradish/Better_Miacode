# 2026-11-08 工作流更新契约

用户已批准开发，基线为上游 dev `be494a567869b407fd17acad33482af6ad1c664d`；Better 迁移点 `c9f14f2790044beaa8ff700da6abaa36aaa27c90` 保留旧发布历史。本文规定目标行为，实际通过范围以验收记录为准。

## 界面与输入

- Alt＋滚轮在 25–300% 连续缩放，保留指针下时间；百分比控件隐藏，既有缩放快捷键仍可用。
- 默认仍为横向时间轴。纵向可位于编辑器之前或之后；默认下落（更晚时间在上方），可切换上落。
- 键位显示顺序：12345678、56781234、87654321、43218765；仅改变投影，不修改谱面。
- Slide 头星、各分支轨迹可独立 Shift 选择；链式整体为一条轨迹，移动星属于轨迹。影响未选组件且无法无损表示的操作必须明确拒绝。
- 防空格误触默认开启，仅用于谱面正文；单次空格立即播放/暂停，三次独立按下在 600 ms 内解锁（相邻≤300 ms），第三次不输入字符。后续空格可输入；失焦/切谱/页面离开重新锁定。自动重复与 IME 候选确认不计入手势。
- Slide 判定时值子选项移到首选项，外部只保留主开关。

## 文档与自动整理

- 高级信息编辑默认关闭，在首选项→关于开启。全局与分难度资料统一写入 maidata，不创建第二份 metadata。
- 填写范围包含试听信息、歌曲/曲师/分类 ID、制式与版本、日期、备注、分难度谱师 ID/规则/定数。显示等级与定数分别保留；ID 保留前导零及合作列表；可选空值不转零。
- seek/wait 作为兼容字段保留。2026-11-08 核查的 Fanmade Portal 新版表单不支持它们，应提示兼容性；不能自动删除或声称整个 metadata 都是网站必填项。
- 自动整理默认开启，触发于首次打开、ZIP、视频/试片任务；普通空格播放和 seek 不触发。
- 整理采用当前默认设置；必须先保存原始磁盘字节到谱面目录 `.autosave/maidata.<SHA256>.bak`，有未保存编辑时还保存整理前编辑快照。备份内容校验，重复内容复用，不覆盖历史备份。
- 分别整理磁盘保存点和当前工作区，避免将未保存难度暗中写盘。成功后一次更新 workspace，原生编辑缓冲保留撤销。
- 音符时点、长音尾、轨迹、修饰和 E 的时点必须一致。解析器 durationSeconds 含最后空 comma 样本，不能用它否决仅改变空拍采样密度的等价整理。
- 备份失败、语义不一致、外部修改、冲突 metadata 时停止自动修改。只读/失败不冒充保存成功。
- ZIP 遇到已存在的空难度默认警告，未创建槽位不算空；语法错误独立处理。继续按钮在左，取消在右并默认聚焦；编辑辅助中可关闭警告。
- ZIP 任务冻结正文、路径及媒体字段，不在文件对话框返回后混用另一文档。输出先暂存，成功后原子替换；取消不得删除原 ZIP。

## 分析与渲染

- 音乐结构和谱面压力分开分析，综合筛选 drop；高 CPS 不等于音乐高潮。人工区间优先；有输入指纹、版本、取消与过期结果拒绝。
- maidata 保存紧凑区间，谱面压力/音频特征保存在产品隔离缓存；demo_seek/demo_len 为共享试听窗口，不等同整段 drop。
- 按用户后续UI修订：压力热图在预览画面最下方半透明叠加，不额外占布局高度；drop 起止在现有进度条上以小标记显示，编辑入口置于标记交互中，不常驻状态行或按钮。缩放时间轴保留淡黄区间。值为相对压力估计，不是官方定数。
- Better 使用纯谱面估计。公开 HandOrder 可附加人工标注特征；自动手序推断和实验代码只进入私有仓库。
- 狐狸非 drop 段按 BPM 摇头，drop 内跳跃，起停/变速/跨区间平滑过渡。
- 低性能模式默认关闭，启用时基础预览目标 60 Hz，自动时间轴刷新与后台分析降载；主动 seek/暂停同步照常。关闭恢复原偏好，离线导出帧率不变。
- 新调试渲染黑底保留谱面，禁止背景媒体解码，集中提供调试显示项。底层支持透明 alpha 合成并做真实像素检查；本轮不新增透明视频/帧导出入口。

## 导出与发布

- 更多显示展开后改为“收起更多”；区间显示并可采用 drop。
- 文件体积：标准、30 MB、100 MB、200 MB、自定义。自定义用目标 Mbps 滑条及输入，显示预计体积；全部模式可独立选择 PV。
- 目标体积计入片头/音频/封装，超限重编码并再次检查；不可静默关闭用户选择的 PV。旧预设按明确规则迁移。
