# dev 候选第二轮反馈

本轮在官方 dev 派生开发线上继续，保留已有编辑、导出和手序能力。用户要求整轮完成后自主验收；开发期间只进行必要构建、状态回归和渲染检查。正式发行仍等待人工确认，不延续上一轮关机任务。

## 验收要求

1. Drop 编辑窗口使用已注册的翻译键。
2. 时间轴 Drop 底色降低透明度，位于音符下方；边缘只显示小字号 `Drop`。
3. 预览底部压力面积降低透明度，支持点击和连续拖动定位，保持播放与暂停状态。
4. 公共压力估计纳入实际几何位移、动作上下文、连续占用和耐力累积/恢复；不生成或保存手序标注，不引入私有自动手序代码。已有人工手序压力适配不重复计算同一负荷。
5. 常规、无理、调试分别保存显示选项，切换和重启均不污染其他模式；常规的两种星星消失效果共享常规配置。
6. 纵向下落播放线靠下，上落播放线靠上。绘制、点击、拖选、缩放和播放跟随使用同一坐标转换。
7. 时间轴独立为面板，语法和无理仍位于编辑器下方。
8. 工作区支持拖动停靠、标签组合、浮动、分隔条缩放、命名布局保存/恢复及预设重置；保持单个编辑文档、撤销历史和预览时钟。顶部加入“工作区”菜单。
9. 方向文案简化为“下落”“上落”；小节线默认项为“默认（自动检测）”；中文快捷键不残留 `Timeline`。
10. 音符尺寸独立于时间缩放，可明显放大，命中和选择范围同步。
11. Drop 桌宠恢复原有律动，非 Drop 使用较轻的 BPM 摇头及身体、尾部跟随，切换连续。
12. 编辑器头部“谱面整理”改为“谱面信息”，通过已有页面导航打开完整信息。保留自动整理和上下文菜单入口。
13. BPM、CPS、统计等信息支持方形、竖屏及自由比例，移除“宽屏”文案；预览与导出复用 HUD 几何，避免越界或互相覆盖。
14. “谱面预览”片头沿用常规预览的背景内外明暗、缩放、皮肤与有效轮廓，关闭调试辅助、时间戳和压力叠加；实时片头和导出使用同一冻结策略。主片段的显式调试导出配置保留。

## 交付边界

- Release 配置，并发上限 4；完成后更新独立测试资源和 HandOrder 派生分支。
- 全部验证使用合成谱或只读源码，不复制、改写正式版配置和真实谱面。
- 公开提交不包含私有自动手序实现。可共享功能与品牌、版本、运行隔离改动分别提交。
- 以本轮构建与验证回执为交付依据，规格本身不代表已通过验收。
