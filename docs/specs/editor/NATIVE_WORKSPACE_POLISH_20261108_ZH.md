# 原生工作区与预览精简

本轮按第三次反馈修订，完成必要自动验证后交由用户自主验收。

1. 编辑预览不绘制重复物量统计，保留窗口下方统计。视频任务独立保留其统计和谱面信息选项。
2. 单面板不增加模块名标题行，通过悬停手柄或实际标签拖动；组合面板保留必要的切换标签。
3. 导航、预览位置、时间轴位置及方向等布局入口集中到“工作区”，首选项不再重复显示旧布局卡片。
4. 工作区可分别隐藏、显示编辑器、预览、大纲、时间轴、语法和无理；隐藏或关闭的面板可从菜单恢复。
5. 默认工作区沿用官方 dev 的原生尺寸规则和左右布局，时间轴、语法、无理共用编辑区下方的一组标签。自定义布局仍可分离。
6. 热图只在实际触击、长音及轨迹占用区间绘制压力，不能把未来负荷向前平滑到留白；疲劳恢复在详情单独保留。
7. Native 和 EraseByArea 在共享最终图层硬屏蔽判定标记、触摸轨迹，旧设置和旧快照不能绕过；Muri/Debug 仍受各自开关控制。
8. 小节线、判定骨骼和 Slide 判定时值是共享显示选项，不重复放进调试菜单，也不由模式切换覆盖。
9. 非 Drop 自然眨眼，Drop 动作闭眼，边界平滑过渡。
10. 工作区入口带 W 助记符。手序版仅在编辑器已有选区且左手动作仍绑定 Alt+W 时优先保留标注操作。
11. 左侧活动栏固定在主窗口，大纲可独立停靠、浮动和隐藏，不携带活动栏移动。
12. 反引号最大化或恢复当前模块；浮窗使用所属窗口的最大化。状态为临时显示，不覆盖保存的布局；普通表单文本输入保留反引号字符。

公开版继续只含人工手序能力；内部自动手序核心保持原有实现。正式发行仍等待用户确认。
