# 手序功能与水印开关

手序拆解和水印自 2026-11-15 起默认关闭。2026-11-17 起，功能开关及可选水印位于“首选项 → 高级”。

自 2026-11-19 起，每次从关闭切换到开启时需要输入离线密码。验证通过后，应用在隔离配置目录保存授权凭据，重启可继续使用；关闭功能会删除凭据。旧配置里的启用标志不授予访问权限。

## 设置与行为

- “启用手序拆解功能”默认关闭。旧配置中已有的手序模式、渲染标志或谱面标注不能自动开启此选项。
- “显示手序拆解水印”独立保存，默认关闭。仅在总功能开启且画面显示手序标注时绘制；预览、视频和谱面画面导出使用同一布尔状态。原谱画面不绘制该水印。
- 关闭功能后默认视频文件名恢复普通的曲名/难度格式，不带手序拆解发布前缀。
- 功能关闭时，手序拆解/模拟游玩模式不可选择，当前这两种模式退回普通渲染；普通渲染的模式循环仍能到达调试模式。三个步骤按钮仍只在手序拆解模式显示。
- 关闭功能会取消手序后台、前台及实验任务，清空待应用的分析证据和候选状态，阻止手序编辑、补全和快捷键，不计算手序压力曲线。普通编辑、分析、预览和导出继续可用。
- 开启后，再从渲染菜单选择“手序拆解”或“模拟游玩”。开启后新打开原谱时沿用手序副本流程；关闭后新打开原谱不创建或优先选择手序副本。切换开关不自动改写、删除或切换当前文档，已有标注仍可读取和保留。
- 控件在运行中生效；已开始的导出使用其任务快照。worker 入口也应用隔离偏好中的功能策略，不能靠旧快照的渲染标志自动启用手序功能。

总开关验证隔离配置目录中的 `hand-order-access-v1` 凭据；水印选项仍保存在 `preferences_v2.json` 的 `app.hand_order_watermark_enabled`。关闭总开关不抹除用户的水印选项，但水印不产生效果。

## 视频导出水印

“首选项 → 高级 → 视频导出水印”可单独启用斜向防盗水印。默认关闭，初始文字为 `Better Miacode`，字号为 48 px。字号可在 16–120 px 之间调整，以视频短边 1080 px 为基准等比缩放。空白文字不绘制，超出画幅的长文字在末尾以省略号收起。

开启后，半透明文字向右上倾斜 30°，交错重复覆盖片头和正片。普通谱面和手序视频均可使用。水印仅写入 MP4 画面。

设置保存在隔离偏好的 `app.video_watermark`。单个和批量导出在启动时记录设置，worker 按任务快照渲染。旧快照缺少此项时视为关闭。CLI 直接导出读取同一份偏好。

## 官方导出策略

按用户同日补充要求，体积与码率功能采用官方 [PR #124](https://github.com/Team-MiaCode/MiaCode/pull/124) 及 [PR #128](https://github.com/Team-MiaCode/MiaCode/pull/128)，核对基线 `e0e9cf2e`。

- 三种策略为画质优先、限制体积、指定码率；编码计划、编码器及配置实现与官方相同，仍优先使用硬件编码器。
- 体积上限是目标值，不是绝对保证。移除本地旧 30/100/200 MB 档、二次重编码、超额成品删除及旧码率预算计算。
- 已有偏好仅按官方规则迁移到画质档，不恢复旧体积行为；独立 PV 选项继续保留。
- CLI 使用 `--rate-mode quality|file_size|bitrate`、`--quality high|standard|small`、`--size-limit-mb 5..1000`、`--video-bitrate 0.1..100`。旧 `--size-preset` 和旧画质参数不再执行。
- worker 使用 `rate_mode`、`quality_level`、`size_limit_mb`、`video_bitrate_kbps`。旧容器格式可以读取当前字段，但包含旧 `preset`、`size_preset`、`target_video_bitrate_mbps` 编码字段的任务明确拒绝，避免无声改变体积预期。

验证回执位于工作区 `exports/handorder_features_20261115/`：偏好和功能策略、停用/启用行为、实际水印画面、官方编码实现比对、归档哈希及固定测试安装均单独记录。测试只使用合成谱面和隔离配置。
