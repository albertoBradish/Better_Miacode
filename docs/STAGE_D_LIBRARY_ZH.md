# 谱库管理候选

入口为工具侧栏的谱库管理，以及工作区菜单中默认隐藏、可停靠/浮动的谱库浏览面板。浏览面板共用同一模型，原文编辑与批量确认仍只在管理窗口中进行；旧六面板布局保持兼容。索引及原文会话由 ApplicationContext 持有，窗口开关和工作区布局不销毁会话。只在用户显式选择目录后扫描，不自动扫描真实官谱库。

- 后台可取消索引 maidata*.txt，保留来源路径、文件 SHA-256、曲名、曲师、显示等级和源 version；不推断拆解完成状态，也不填充未知拆解人、编号或主库定数。
- 搜索按路径及元数据多个词取交集；相同内容文件按字节哈希分组，不把同曲不同版本视为可删除副本。缓存使用大小/修改时间增量更新，监听最多512个目录和2048个文件，大库其余变动通过手动刷新读取。索引最多100000项且元数据预算64MiB，超限会显示异常/上限事件。
- 原文多文档会话最多5份、每份4MiB；独立dirty、revision和撤销，历史约8MiB上限，保存在本产品独立runtime的sessions。主谱面编辑器/预览仍一次持有一曲；谱库原文会话不加载音频或PV，不宣称是完整多预览工作区。
- 保存按原始磁盘哈希检测外部冲突，保留UTF-8 BOM和CRLF，使用QSaveFile原子写入并备份原始字节。非UTF-8文件保留原文并拒绝编辑，不静默转码。
- 批量格式化复用准备时的当前谱面整理设置，只处理显式选中项目，一次最多100份、合计16MiB，先生成差异摘录，再确认应用。修改前全量复核、校验备份；每次写入重新检查路径和原文。失败/取消会尝试回滚已写文件，若遇外部修改则保留外部数据并记recovery_required日志供人工恢复。
- 批量操作拒绝主编辑器或原文会话中打开的文件；最近一次成功批量操作可撤销，撤销也要求当前字节仍是本次写入结果。索引移除不删除文件。本轮不提供批量移动或删除媒体。
- 正文规范化仅替换inote值，其他未知字段、顺序及多行值保留；使用各产品既有玩法语义签名检查类型、位置、时序、轨迹等，手序版还比较人工标注。重复字段和非法语法需先人工处理。

验证使用工作区临时合成文件，ChartLibrarySpec覆盖冲突、备份、回滚、会话与恢复；--performance提供1000/10000项测量。GUI由用户本地验收，不自动操作真实谱库或管理台账。
