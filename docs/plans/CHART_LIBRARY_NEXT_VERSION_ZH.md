# 下一功能版本：谱库管理开发日程

状态：可行性研究已完成，已列入下一功能版本待评审日程；本轮不实现目录索引或多曲目管理，也不扫描、迁移用户谱库。

## 结论与现状

可以在现有“谱面”模块和标签页交互上扩展，但当前标签页主要是同一曲目的难度与信息视图，不能直接视为多曲目会话。

`ApplicationServices` 持有单个 `ChartWorkspace`，`DocumentModel`、分析投影和播放协调器围绕该工作区装配。Scintilla 已按难度保存独立文档缓冲、撤销和视口，具备复用基础；多曲目需要在作用域中增加曲目会话身份，而不能仅换文件路径。音频和预览资源应只附着于活动曲目。

已有可复用能力包括：元数据模型、媒体路径解析、文件保存事务、原字节备份、外部修改检测、带 revision/generation 的分析结果、文档页面路由，以及本轮的结构/压力缓存和导出快照。

## 开发顺序

| 里程碑 | 范围 | 放行条件 |
| --- | --- | --- |
| L0：规格与数据边界 | 确认曲目/难度/版本的身份、加入目录规则、文件操作与退出行为 | 产品规格、页面草图与接口审阅完成后再编码 |
| L1：只读谱库索引 | 用户显式加入目录，浏览、搜索、筛选、增量刷新、失联提示 | 仅索引允许的根目录，可取消；大目录不阻塞活动谱面预览 |
| L2：多曲目标签与会话 | 曲目标签下保留难度/信息标签，每曲独立修改状态与撤销 | 切换不串谱、不丢未保存编辑；旧异步结果不进入新标签 |
| L3：文件与媒体管理 | 新建、重命名、移动、删除及关联资源处理 | 预演影响、冲突检测、备份、失败回滚和外部修改处理通过 |
| L4：批量操作与收尾 | 多曲元数据操作、导出队列、恢复、性能与迁移文档 | 每曲任务隔离失败；跨曲恢复、队列取消和资源上限验证通过 |

顺序为 L0 → L1 → L2 → L3 → L4。L1 可先交付只读管理入口；L3 不作为 L1 的隐式功能提前开放。具体日历日期在当前版本验收和 L0 评审后确定。

## 拟议结构

以下是设计名称，尚未实现：

- `LibraryIndexService`：目录注册、轻量元数据索引、文件监听与更新任务，不持有活动编辑器的可写文档。
- `ChartSessionRegistry`：每曲独立的 workspace、保存点、revision、撤销、恢复记录和视口。
- 活动会话适配：现有 `DocumentModel` 与播放/预览只绑定一个明确的活动会话；切换前提交输入，取消旧任务并完成音频交接。
- 文件操作事务：与索引层分开，针对用户明确选择的文件集合处理移动、重命名、删除与媒体引用。

```text
谱库目录 / 搜索 / 筛选       曲目 A * | 曲目 B | +
  用户加入的目录               难度 | 谱面信息
  曲目与版本                   编辑区 | 时间轴 | 预览
  离线或待核对状态             当前曲目的导出与分析状态
```

## 必须保持的边界

- 文件仍留在用户加入的目录；索引不是一份自动复制的谱库。
- 默认不跟随目录链接越过已加入根目录；路径归一化、盘符变更、同名目录和只读目录必须明确处理。
- 路径、曲目 ID、文件内容指纹用途分开。相同音频或同名歌曲不自动合并不同谱面、制式和版本。
- 谱师、手序拆解人、源定数、显示等级和参考定数保持独立，不从文件名或其他作者字段猜测完成状态和署名。
- 从管理列表移除与删除磁盘文件是不同命令；既有历史清理授权不能用于新功能的自动删除。
- 每条异步结果、保存回调和编辑命令携带会话 ID、revision 与代次。不同曲目出现相同 revision 数字也不能互相应用结果。
- 每曲独立 dirty 与撤销。切换标签不能重建并清空另一个曲目的 Scintilla 历史。
- 工作区级备份、缓存、恢复与用户正式应用的偏好保持隔离；不自动导入正式版配置或恢复文件。
- 只有活动曲目持有实时播放设备和主要预览资源；非活动曲目采用懒加载，设置明确的内存与后台任务预算。
- 本轮导出快照、drop 与压力缓存的来源身份继续保留，下一版扩展为会话作用域，不能退回按当前界面状态读取浮动参数。

## 验收材料与风险

使用新生成的多曲目、多难度夹具验证：重复标题与不同版本、中文和长路径、只读文件、失联盘符、外部修改、同时存在未保存修改、失败恢复和取消。

关键风险是多文档生命周期与文件事务，不能用“目录树显示出来了”代替完成。L2 至少验证双曲互切、各自撤销与关闭提示、分析中切曲和恢复；L3 验证跨卷移动中断、关联媒体相对路径、重名冲突及回滚；L4 验证一曲失败不污染其他任务。

是否采用数据库及其具体索引结构，在 L1 原型用量测结果决定。当前版本不为尚未实现的谱库功能提前重构整个 Session。
